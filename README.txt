MySpensab Download Portal

This is a separate, lightweight static website. Keep it in its own folder; it does not need to be placed inside the main Aventra-NextJS/VSCODE/html project.

Files:
- index.html: the standalone download and installation portal.

The portal links Windows users to the MySpensab Setup installer release and guides Android, Mac, and iPhone users to install the web app from the official site. The portal folder itself does not contain native APK, DMG, or IPA packages.

To edit it, open this folder in VS Code. It can be deployed separately as its own static site.
